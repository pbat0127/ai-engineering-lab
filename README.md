# AI Engineering Lab

My hands-on practice repository on the path to becoming an AI Engineer.
Every exercise here is rewritten from scratch by me (no copy-paste from course notebooks) and extended with my own use cases.

## Structure

| Folder | Content |
| --- | --- |
| `llm-engineering/` | Exercises and assignments from the LLM Engineering course, rewritten and extended |
| `python-fundamentals/` | Python practice: data structures, files, testing |

## Setup

```bash
uv sync                 # install dependencies
cp .env.example .env    # then add your own API keys
```
